# Мёртвый сигнал — Android-проект

Внутри игра (`app/src/main/assets/index.html`) в полноэкранном приложении:
горизонтальный экран, экран не гаснет, кнопка «Назад» закрывает меню и ставит паузу
(двойное нажатие — выход). Нужен Android 8.0 или новее.

## Способ 1. Без установки программ — через GitHub
1. Зарегистрируйся на github.com и создай новый репозиторий (New repository).
2. Загрузи в него все файлы из этой папки: Add file → Upload files.
   Скрытая папка `.github` тоже должна попасть в репозиторий — проще всего
   перетащить содержимое папки целиком в окно браузера.
3. Открой вкладку Actions: сборка запустится сама и займёт около 5 минут.
4. Открой завершённую сборку и внизу, в разделе Artifacts, скачай `DeadSignal-apk`.
   Внутри архива лежит `app-debug.apk`.

## Способ 2. Android Studio
1. Установи Android Studio: developer.android.com/studio
2. File → Open → выбери эту папку и дождись окончания синхронизации.
3. Build → Build App Bundle(s) / APK(s) → Build APK(s).
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Установка на телефон
Скопируй APK на телефон, открой его и разреши установку из неизвестных источников.

## Важно
- Для первого запуска нужен интернет: движок 3D-графики (three.js) загружается из сети,
  потом WebView его кеширует.
- Для полностью офлайн-версии скачай файлы из тегов `<script src=...>` в начале
  `index.html`, положи их в `app/src/main/assets` и замени ссылки на локальные пути.
- Для публикации в Google Play нужна подписанная сборка:
  Build → Generate Signed App Bundle / APK.
